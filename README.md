# Микросервисное REST-приложение для "шеринга" (обмена вещами) между пользователями с возможностями бронирования и резервирования вещей
___

## Описание
___
В нашем приложении вы можете:
1. Арендовать вещь (для зарегистрированного пользователя) у другого зарегистрированного пользователя.
2. Выложить свою вещь (для зарегистрированного пользователя) для аренды другим пользователем.
3. Создать запрос на нужную Вам вещь (для зарегистрированного пользователя), если объявлений аренды такой вещи нет.
4. Посмотреть описание вещи, которую можно арендовать (для всех пользователей).

## Принцип работы
___

Микросервисное REST-приложение выполнено с помощью SpringBoot. На входе запросы принимает шлюз, затем отправляет запросы в нужный микросервис. Реализован только один основной микросервис.
1. **Хранение данных** реализовано в базе данных. Для тестирования используется H2. Для работы приложения - PostgreSQL. Для доступа к данным используется Spring Data JPA.
2. **Валидация данных** выполняется в моделях при помощи аннотаций Java Bean Validation, а также в сервисном слое.
3. **Обработчик ошибок** используется собственной реализации.
4. **Тестирование** выполнено при помощи JUnit. Реализовано:\
   1. Тесты для эндпоинтов контроллеров при помощи MockMVC.
   2. Юнит-тесты для сервисного слоя при помощи моков.
   3. Тесты репозиториев при помощи DataJpaTest.
   4. Интеграционные тесты для одного метода в каждом сервисном слое.
